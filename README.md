# ConnectLines
Welcome to ConnectLines, a social networking app built with Jetpack Compose and Kotlin. ConnectLines allows users to connect, follow each other, and share posts known as "lines"—a combination of images and text. This app leverages the power of Jetpack Compose for UI and Firebase for real-time backend support.

## Features
User Authentication: Seamless login and registration system with email verification and secure login flows using Firebase Authentication.  
Create and View Lines: Users can create new lines and view existing ones, with an elegant and responsive UI designed using Jetpack Compose.  
Follow and Followers: Users can follow each other, with intuitive UI elements showcasing follower and following lists.  
User Profiles: Engaging user profiles that display relevant information and user-generated content.  
Real-time Updates: Integrated Firebase to ensure real-time updates for lines, followers, and other crucial components.  

## Dependencies
